# Data dictionary

## Provenance and grain

The included data files are inherited from the project adaptation credited upstream to [Ashutosh Sahoo](https://github.com/Ashuytosh/Blinkit_Data_Analysis). The upstream project materials in this repository do not identify a separate publisher or license for the dataset itself; the exact original dataset source and redistribution terms therefore remain unverified. Confirm them before republishing the data elsewhere.

Each row is an item/outlet record in the supplied snapshot. It is not a transaction-level ledger: there is no transaction date, sold quantity, or order identifier. The source does not specify the currency or measurement period for `Total Sales` / `Sales`.

## Fields

| Raw CSV field | Cleaned CSV field | Meaning | Observed data type | Notes |
|---|---|---|---|---|
| `Item Fat Content` | `Item Fat Content` | Product fat-content category | Text/category | Raw values include `LF`, `low fat`, and `reg`; normalized in the cleaned file to `Low Fat` and `Regular`. |
| `Item Identifier` | `Item Identifier` | Product identifier | Text/category | Not a unique row identifier. |
| `Item Type` | `Item Type` | Product category | Text/category | 16 categories observed. |
| `Outlet Establishment Year` | `Outlet Establishment Year` | Outlet establishment year | Integer | Outlet attribute, not a transaction date. |
| `Outlet Identifier` | `Outlet Identifier` | Outlet identifier | Text/category | 10 identifiers observed. |
| `Outlet Location Type` | `Outlet Location Type` | Outlet location tier | Text/category | Tier 1, Tier 2, and Tier 3 observed. |
| `Outlet Size` | `Outlet Size` | Outlet size category | Text/category | Small, Medium, and High observed. |
| `Outlet Type` | `Outlet Type` | Outlet format | Text/category | Grocery Store and Supermarket types observed. |
| `Item Visibility` | `Item Visibility` | Recorded visibility measure | Decimal | Inherited definition/scale is not further documented; descriptive analysis only. |
| `Item Weight` | `Item Weight` | Recorded item weight | Decimal | 1,463 missing values in the supplied snapshot; retained without imputation. |
| `Total Sales` | `Sales` | Recorded sales value for a row | Decimal | 8,523 values; no currency or period specified. |
| `Rating` | `Rating` | Recorded rating | Decimal | Observed range is 1–5. |
| — | `Outlet Age` | Derived field in supplied cleaned CSV | Integer | Equals 2025 minus establishment year. It is anchored to 2025 and is not generated by the refreshed cleaning workflow. |

## Supplied file checks

- Raw CSV: 8,523 rows × 12 columns.
- Cleaned CSV: 8,523 rows × 13 columns; standardized fat-content labels, renamed `Total Sales` to `Sales`, and added `Outlet Age`.
- Exact duplicate rows: 0 in each CSV.
- Missing values: 1,463 in `Item Weight`; no missing values in the other cleaned snapshot columns.
- Raw and cleaned CSVs contain the same population in different representations. Do not append them together.
